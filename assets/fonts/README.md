# Fonty

Místně hostované Inter (proměnná síla 400–700) a Barlow Condensed Bold (700). Podmnožiny latin a latin-ext ve formátu WOFF2 zahrnují české znaky. `font-display: swap` zachovává čitelnost při načítání; systémové bezpatkové písmo slouží jako záloha. Návštěvník nekontaktuje Google Fonts.

Původní soubory bez úprav pocházejí z oficiálního Google Fonts CSS API: https://fonts.googleapis.com/css2?family=Barlow+Condensed:wght@700&family=Inter:wght@400..700&display=swap (staženo pro M1.2).

Obě rodiny používají SIL Open Font License 1.1. Úplné licence jsou v `inter-OFL.txt` a `barlowcondensed-OFL.txt`. Zdroj projektů a licencí: https://github.com/google/fonts/tree/main/ofl/inter a https://github.com/google/fonts/tree/main/ofl/barlowcondensed.
